# Copy-ready template bodies

The index links to the scenario-specific files. This file is retained as a
compact reference for the shared safe wording.

## Internal header

```text
Severity: [Critical|High|Medium|Low / Sev-1|Sev-2|Sev-3]
Status: [Investigating|Contained|Recovering|Resolved]
Owner: [Incident Commander]
Next update: [UTC timestamp or cadence]
```

## External-safe body

```text
We are investigating a service or security issue affecting [high-level area].
As a precaution, [pause/maintenance/mitigation] is in effect. We are not
sharing operational details while the response is active. User action:
[none / approved instruction]. Status: [status]. Next update: [UTC time].
```
